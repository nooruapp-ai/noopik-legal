隐私政策

生效日期：2026年10月14日

使用 NOOPIK 订阅服务，需要通过电子邮箱或 Apple、Google、LINE 账号登录。注册时需填写昵称。NOOPIK 不会直接索取或保存银行卡信息；当您开始 7 天免费试用或订阅时，由 Apple App Store 或 Google Play 核验付款方式。

1. 保存在设备上的信息 详细学习进度、答对与答错记录、学习统计、保存的单词、笔记和通知设置，会保存在当前设备或浏览器的本地存储空间中。为便于已登录账号的设备之间恢复和同步学习数据，我们还会在服务器上保存一份大小受限的学习快照及账号 ID。快照包含答题正误、复习记录、内容展示记录、统计、保存的单词、高亮标记和个人笔记。支持此功能的版本也会同步删除标记，防止已删除的项目在其他设备上重新出现。请勿在个人笔记中填写密码、银行卡号或不必要的个人信息。您未主动申请付费批改的写作答案原文，不会纳入学习快照。

2. 学习账号与设置同步 使用电子邮箱或 Apple、Google、LINE 登录时，我们会在服务器上保存 Supabase 用户 ID、登录方式、电子邮箱地址（如有提供）、您填写的昵称、测定等级、目标等级、考试日期、语言及初始设置的完成状态。通过电子邮箱注册的登录密码，由 Supabase Auth 作为加密认证信息处理，NOOPIK 运营人员无法查看密码原文。NOOPIK 不会收集或保存 Apple、Google、LINE 账号的密码。LINE 登录使用 openid 和 profile 权限范围；LINE 用户标识符、显示名称及个人资料图片链接（如有），会用于 Supabase 身份认证和账号关联确认。我们不会申请获取 LINE 电子邮箱地址的权限。

3. 使用付费批改时收集的信息 当前正式发布的版本不提供付费批改功能。只有在今后的其他版本提供此功能，并且您主动提出申请时，我们才会收集写作任务与答案、账号 ID、语言、App Store 或 Google Play 的商品及购买标识符、购买验证信息、申请状态和教师反馈。我们不收集银行卡信息。

4. 反馈题目问题时收集的信息 当您在题目页面提交问题反馈时，系统会发送账号 ID、题目代码、当前显示的题目、选项、正确答案、解析、听力文本、评定等级、内容版本、反馈类型及您自行填写的内容。反馈工单不包含姓名、电子邮箱地址或电话号码。为防止重复反馈，应用安装实例和连接网络的标识值会以不可还原的哈希值保存。反馈仅用于核查和改进内容以及防止不当使用，不会自动修改原始题目。

5. 使用目的与处理服务商 收集的信息仅用于登录与设置同步、付款核验、答案传送、提供教师批改、结果查询、处理题目问题反馈、客户支持、防止不当使用，以及改善服务稳定性和学习流程。服务器存储和电子邮箱账号认证使用 Supabase；社交账号登录由 Apple、Google、LINE 提供；付款通过 Apple App Store 或 Google Play 处理，并使用 RevenueCat 核验购买状态。运营分析使用 PostHog，仅发送应用启动、完成注册、水平测试、开始学习、是否答对、是否复习、完成数量、连续学习天数、发生错误的区域及错误类型，并附上随机生成的安装分析 ID。分析事件不包含电子邮箱地址、昵称、账号 ID、题目、选项、答案或解析的原文、语音和照片。我们不使用 PostHog 的个人档案创建、自动采集或会话回放功能，并停用基于 IP 地址为分析事件补充位置信息的功能。银行卡信息由 Apple 或 Google 处理，NOOPIK 和 RevenueCat 均不会接收。

6. 广告与跟踪 免费方案仅在您选择额外学习时，提供 Google AdMob 激励广告。如果广告尚未配置或无法提供，则不会显示。我们不提供强制全屏广告或横幅广告，Pro 也不会显示学习广告。我们请求非个性化广告，不会请求跨其他公司的应用与网站进行跟踪。非个性化广告并不意味着不处理数据。Google Mobile Ads SDK 可能为了投放广告、防止不当使用及进行诊断，处理 IP 地址及据此推算的大致位置、设备与应用标识符、广告展示与互动，以及错误与性能信息。NOOPIK 不会在广告请求中加入电子邮箱地址、昵称、答案、题目或解析原文，也不会向数据经纪商出售收集的信息。我们会根据适用地区和同意状态显示 Google 的隐私同意页面，并在需要更改时，在设置中提供广告隐私设置。

为管理免费学习额度并防止广告奖励重复发放，设备会保存对账号 ID 进行哈希处理后生成的标识符、日本时间的日期、各学习领域的剩余额度、使用过的内容 ID 及奖励标识符。在按设备管理额度的版本中，这些记录仅用于当前设备的使用限制，不会跨设备同步。记录会单独保存，以防退出登录或重置学习记录后再次获得额度；删除账号时，会删除当前设备上的相关记录。删除应用或更换设备后，不保证能够恢复按设备保存的记录。

在启用服务器额度管理的版本中，服务器也会保存账号 ID、日本时间的日期、学习领域、使用过的内容 ID 与使用量、奖励请求及交易标识符、奖励数量和处理时间。这些记录用于对登录同一账号的设备实施使用限制，并防止奖励重复发放。对于由服务器验证的激励广告，我们会向 Google 发送账号 ID、随机生成的奖励请求标识符及学习领域，将带有签名的奖励关联到对应账号和请求。账号 ID 不是电子邮箱地址，但可识别 NOOPIK 账号。服务器上的额度记录也属于账号删除的处理范围。广告服务商的数据处理和保存适用其自身政策。

使用统计和错误报告默认关闭。可自主选择是否同意的设置，会在支持该功能的更新版本中提供；如果看不到相关设置，请检查应用更新或联系支持人员。只有您在设置中主动同意后，我们才会收集并发送上述分析事件；不同意不会改变付费功能的使用条件。您可以随时在设置中关闭。关闭后，我们会停止新的分析数据收集和发送，并删除设备上尚未发送的分析队列及安装分析 ID。已发送至服务器的事件，不会仅因这一操作就立即删除。分析不会发送错误消息或堆栈跟踪的原文。

7. 保存与删除 本地学习信息会保存至您在设置中执行“重置本设备的学习记录”，或删除应用为止。待发送的匿名分析事件在设备上最多保存 64 条，且不超过 7 天；发送完成后，会从设备队列中删除。重置本地记录不会删除服务器账号或批改记录。您可通过“删除账号及服务器数据”申请删除账号。完成必要的身份核验后，我们会执行删除流程，处理服务器上的登录账号、设置、学习快照、批改申请与结果，以及当前设备上的账号数据。我们也会确认必要的外部服务处理，包括删除 RevenueCat 客户信息及解除 Apple 登录关联。由于应用版本或外部服务状态，流程可能无法完成。如遇错误，或需确认删除范围，请联系 support@noopik.app。支持人员会在核验身份后，说明尚待处理的范围与进度。法律规定须另行保存的付款记录，可能会在规定期限内继续保留。

8. 设备权限 仅在您开启学习通知时，我们才会申请通知权限。如果您在页面上主动选择附加照片，我们会使用所选照片处理该项请求。请勿发送包含密码、银行卡号或不必要个人信息的照片。您可以随时在设备设置中更改权限。

9. 隐私咨询与删除协助 如果无法在应用内删除数据，或有个人信息相关问题，请联系 support@noopik.app。

10. 运营方 本服务运营方：NOOPIK 运营团队。联系方式：support@noopik.app

11. 客户支持邮件 当您通过 support@noopik.app 联系我们时，我们会处理发件邮箱地址、显示名称、主题、正文、收件时间及回复记录。邮件收发使用 Cloudflare，管理员咨询收件箱的存储使用 Supabase。常规咨询收件箱不保存附件内容，仅保存附件数量。如果因收件处理失败、大小限制等原因，将邮件转交至工作人员的另一个支持邮箱，该邮箱可能会保存包含附件的原始邮件。咨询时请只提供解决问题所需的信息，不要发送密码、验证码或银行卡号。

咨询记录会在处理咨询及后续确认所需的期间内保存；问题解决后，我们会重新评估保存的必要性，删除不再需要的个人信息。未自动关联账号的邮件，或单独支持邮箱中的记录，可能不会仅因删除应用账号而全部删除。如需删除咨询记录，请提供发件地址和联系时间。提供或删除账号相关个人信息前，我们会另行核验身份，不会仅凭邮件显示的发件人信息处理。

12. 外部服务的保存、删除与备份 服务器账号和学习快照会在提供服务所需的期间内保存，并根据账号删除申请进行处理。题目问题反馈中留下的、无法识别个人身份的内容改进记录，可能会独立于账号删除流程继续保存。已发送至 PostHog 的事件、Cloudflare 处理记录、单独的支持邮箱，以及 Apple、Google 的购买与退款记录，适用各处理服务商的保存政策和法定义务。设备队列的 7 天上限并不代表所有外部服务器的保存期限。适用的保存期限及删除协助，可向支持人员确认。用于恢复的备份副本与正在使用的数据分开管理，可能会保留至该备份的保存周期结束。删除账号或应用，不等于取消商店订阅。
