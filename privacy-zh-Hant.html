隱私權政策

生效日期：2026年10月14日

使用 NOOPIK 的訂閱服務，須透過電子郵件或 Apple、Google、LINE 帳號登入。註冊過程中需輸入暱稱。NOOPIK 不會直接要求提供或儲存卡片資料；當您開始 7 天免費試用或訂閱時，付款方式由 Apple App Store 或 Google Play 確認。

1. 儲存在裝置上的資訊 詳細學習進度、答對與答錯紀錄、學習統計、已儲存的單字、筆記及通知設定，會儲存在此裝置或瀏覽器的本機儲存空間。為了讓登入同一帳號的裝置能還原及同步學習資料，我們也會將容量有限的學習快照連同帳號 ID 儲存在伺服器上。快照包含答對與答錯紀錄、複習紀錄、內容顯示紀錄、統計、已儲存的單字、重點標記與個人筆記。支援此功能的版本也會同步刪除標記，避免已刪除的項目在其他裝置重新出現。請勿在個人筆記中填寫密碼、卡號或不必要的個人資料。未由您主動要求付費批改的寫作答案原文，不會納入學習快照。

2. 學習帳號與設定同步 使用電子郵件或 Apple、Google、LINE 登入時，我們會在伺服器上儲存 Supabase 使用者 ID、登入方式、電子郵件地址（如有提供）、您輸入的暱稱、測定級數、目標級數、考試日期、語言及初始設定的完成狀態。以電子郵件註冊的登入密碼，由 Supabase Auth 以加密的驗證資訊處理，NOOPIK 營運人員無法查看密碼原文。NOOPIK 不會蒐集或儲存 Apple、Google、LINE 帳號的密碼。LINE 登入使用 openid、profile 權限範圍；LINE 使用者識別碼、顯示名稱及個人檔案圖片網址（如有），會用於 Supabase 身分驗證及帳號連結確認。我們不會要求存取 LINE 電子郵件地址的權限。

3. 使用付費批改時蒐集的資訊 目前正式公開的版本沒有付費批改功能。僅在未來的其他版本提供此功能，且您主動提出申請時，我們才會蒐集寫作題目與答案、帳號 ID、語言、App Store 或 Google Play 的商品與購買識別碼、購買確認資訊、申請狀態及教師回饋。我們不會蒐集卡片資料。

4. 回報題目問題時蒐集的資訊 當您在題目畫面送出問題回報時，系統會傳送帳號 ID、題目代碼、目前顯示的題目、選項、正確答案、解析、聽力逐字稿、判定級數、內容版本、回報類型及您自行輸入的內容。回報單不會包含姓名、電子郵件地址或電話號碼。為防止重複回報，應用程式安裝實例與連線網路的識別值會以無法還原的雜湊值儲存。回報僅用於確認與改善內容，以及防止不當使用，不會自動變更原始題目。

5. 使用目的與處理服務商 蒐集的資訊僅用於登入與設定同步、付款確認、答案傳送、提供教師批改、結果查詢、題目問題回報處理、客戶支援、防止不當使用，以及改善服務穩定性與學習流程。我們使用 Supabase 儲存伺服器資料及驗證電子郵件帳號，透過 Apple、Google、LINE 提供社群帳號登入，使用 Apple App Store 或 Google Play 處理付款，並透過 RevenueCat 確認購買狀態。營運分析使用 PostHog，僅傳送應用程式啟動、完成註冊、程度測驗、開始學習、是否答對、是否複習、完成數量、連續學習天數、錯誤發生區域及錯誤類型，並附上隨機產生的安裝分析 ID。分析事件不包含電子郵件地址、暱稱、帳號 ID、題目、選項、答案或解析的原文、語音及照片。我們不使用 PostHog 的個人檔案建立、自動蒐集或工作階段重播功能，也停用依據 IP 位址為分析事件補充位置資訊的功能。卡片資料由 Apple 或 Google 處理，NOOPIK 與 RevenueCat 不會接收。

6. 廣告與追蹤 免費方案僅在您選擇額外學習時，提供 Google AdMob 的獎勵式廣告。廣告尚未設定或無法使用時，不會顯示。我們不提供強制全螢幕廣告或橫幅廣告，Pro 也不會顯示學習廣告。我們會請求非個人化廣告，不會要求跨其他公司的應用程式與網站進行追蹤。非個人化廣告並不代表完全不處理資料。Google Mobile Ads SDK 可能為了投放廣告、防止不當使用及進行診斷，處理 IP 位址及據此推算的大致位置、裝置與應用程式識別碼、廣告曝光與互動，以及錯誤與效能資訊。NOOPIK 不會在廣告請求中加入電子郵件地址、暱稱、答案、題目或解析原文，也不會將蒐集的資訊出售給資料仲介商。我們會依適用地區與同意狀態顯示 Google 的隱私權同意畫面，並在需要變更時，於設定中顯示廣告隱私權設定。

為管理免費學習額度並防止廣告獎勵重複發放，裝置會儲存帳號 ID 經雜湊處理後的識別碼、日本時間的日期、各學習領域的剩餘額度、使用過的內容 ID 及獎勵識別碼。採用裝置別額度的版本，僅將這些紀錄用於目前裝置的使用限制，不會在裝置間同步。這些紀錄會另外保存，以免登出或重設學習紀錄後再次獲得額度；刪除帳號時，則會刪除此裝置上的相關紀錄。刪除應用程式或更換裝置後，不保證能還原裝置別紀錄。

啟用伺服器額度管理的版本，也會在伺服器上儲存帳號 ID、日本時間的日期、學習領域、使用過的內容 ID 與使用量、獎勵請求與交易識別碼、獎勵數量及處理時間。這些資料用於對登入同一帳號的裝置套用使用限制，並防止獎勵重複發放。對於由伺服器驗證的獎勵式廣告，我們會將帳號 ID、隨機產生的獎勵請求識別碼及學習領域傳送給 Google，將具簽章的獎勵對應至該帳號與請求。帳號 ID 並非電子郵件地址，但可用來識別 NOOPIK 帳號。伺服器上的額度紀錄也包含在帳號刪除的處理範圍內。廣告服務商的資料處理與保存，適用該服務商的政策。

使用統計與錯誤回報預設為關閉。可自行選擇是否同意的設定，會在支援此功能的更新版本中提供；若看不到相關設定，請檢查是否有應用程式更新，或聯絡支援窗口。只有您在設定中主動同意後，我們才會蒐集並傳送上述分析事件；不同意也不會影響付費功能的使用條件。您可以隨時在設定中關閉；關閉後，我們會停止新的分析蒐集與傳送，並刪除裝置上尚未傳送的分析佇列及安裝分析 ID。已傳送至伺服器的事件，不會僅因這項操作而立即刪除。分析不會傳送錯誤訊息或堆疊追蹤的原文。

7. 保存與刪除 本機學習資訊會保存到您在設定中執行「重設此裝置的學習紀錄」，或刪除應用程式為止。待傳送的匿名分析事件在裝置上最多保存 64 筆，且不超過 7 天；傳送完成後，便會從裝置佇列中刪除。重設學習紀錄不會刪除伺服器帳號或批改紀錄。您可透過「刪除帳號與伺服器資料」提出帳號刪除申請。完成必要的身分驗證後，我們會進行刪除程序，處理伺服器上的登入帳號、設定、學習快照、批改申請與結果，以及此裝置上的帳號資料。我們也會確認必要的外部服務處理，例如刪除 RevenueCat 客戶資訊及解除 Apple 登入連結。程序可能因應用程式版本或外部服務狀態而無法完成。如發生錯誤，或您希望確認刪除範圍，請聯絡 support@noopik.app。支援窗口會在完成身分驗證後，說明尚待處理的範圍與進度。依法須另外保存的付款紀錄，可能會在規定期間內繼續保存。

8. 裝置權限 只有在您開啟學習通知時，我們才會要求通知權限。若您在畫面上主動選擇附加照片，我們會使用所選照片處理該項請求。請勿傳送含有密碼、卡號或不必要個人資料的照片。您可以隨時在裝置設定中變更權限。

9. 隱私權諮詢與刪除協助 若無法在應用程式內刪除資料，或有個人資料相關問題，請聯絡 support@noopik.app。

10. 營運者 本服務營運者：NOOPIK 營運團隊。聯絡方式：support@noopik.app

11. 客戶支援電子郵件 當您透過 support@noopik.app 聯絡我們時，我們會處理寄件電子郵件地址、顯示名稱、主旨、內文、收件時間及回覆紀錄。郵件收發使用 Cloudflare，管理員諮詢信箱的儲存則使用 Supabase。一般諮詢信箱不會儲存附件內容，只儲存附件數量。若因收件處理失敗、大小限制等原因，將郵件轉交至承辦人員的另一個支援信箱，該信箱可能會保存包含附件的原始郵件。來信請只填寫解決問題所需的資訊，勿傳送密碼、驗證碼或卡號。

諮詢紀錄會保存至處理諮詢與後續確認所需的期間；問題解決後，我們會重新評估保存必要性，刪除不必要的個人資料。未自動連結至帳號的郵件，或另一個支援信箱中的紀錄，可能不會僅因刪除應用程式帳號而全部刪除。如需刪除諮詢紀錄，請提供寄件地址及聯絡時間。對於帳號相關個人資料的提供或刪除，我們不會只憑郵件顯示的寄件者資訊處理，而會另行驗證身分。

12. 外部服務的保存、刪除與備份 伺服器帳號與學習快照會在提供服務所需的期間內保存，並依帳號刪除申請進行處理。題目問題回報中留下的、無法識別個人身分的內容改善紀錄，可能會獨立於帳號刪除程序繼續保存。已傳送至 PostHog 的事件、Cloudflare 處理紀錄、另外的支援信箱，以及 Apple、Google 的購買與退款紀錄，適用各處理服務商的保存政策及法定義務。裝置佇列的 7 天上限，並不代表所有外部伺服器的保存期限。適用的保存期間與刪除協助，可向支援窗口確認。用於復原的備份副本會與使用中的資料分開管理，並可能保存至該備份的保存週期結束。刪除帳號或應用程式，不等於取消商店訂閱。
